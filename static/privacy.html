Privacy Policy & Telemetry Data Governance

Effective Date: October 6, 2026 | Document ID: PMG-POL-01

ACTIVE POLICY

1. Scope of This Policy

This Privacy Policy governs how Predictive-Machine Guard processes, stores, and transmits industrial sensor telemetry, uploaded comma-separated value (CSV) datasets, and client browser preferences when you access this web application.

2. Industrial Telemetry & Uploaded CSV Datasets

When you upload a custom manufacturing CSV file via the CSV Ingestion Studio:

  • Uploaded sensor records are parsed in volatile memory solely to execute missing-value imputation, Tukey 1.5xIQR outlier Winsorization, and model evaluation.
  • Uploaded custom datasets are not sold, shared with external third parties, or used to train third-party commercial foundation models.
  • You may export and download your processed dataset at any time using the Export CSV control.

3. Personal Data & Account Information

Predictive-Machine Guard operates as a technical engineering and machine learning workbench. The application does not require user registration, does not collect names, email addresses, payment details, or geolocation coordinates, and does not embed third-party advertising trackers or behavioral analytics scripts.

4. Local Browser Storage & Cookies

This application does not set tracking cookies. A single client-side key (pmg_theme) is stored in your browser's localStorage to remember your display preference (`dark` or `light` mode) across sessions. You can clear this key at any time through your browser settings.

5. Network Logs & Security

Standard HTTP request metadata (request path, timestamp, and HTTP status code) is processed transiently to serve application assets and telemetry evaluation endpoints. All public deployments enforce Transport Layer Security (`HTTPS / TLS 1.3`) for data in transit.

6. Contact & Compliance Inquiries

For questions regarding telemetry data handling, dataset benchmarking, or academic/industrial compliance, please contact the Predictive-Machine Guard engineering maintainer via the repository or deployment administrator channel.
